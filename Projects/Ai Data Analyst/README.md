# AI Data Analyst

A simple app where you upload a CSV file and get instant analysis.

## Features
- Upload any CSV file
- Rows, columns and missing values
- Statistics and correlation
- Bar charts and distribution charts
- Ask questions in plain English (total, average, highest, lowest, by group)

## Tech Used
Python, Pandas, NumPy, Streamlit

## Run Locally
```
pip install -r requirements.txt
python generate_data.py
streamlit run app.py
```
