# AI Career Advisor

A simple AI app that suggests careers based on your skills and interests.

## How it works
1. The user selects skills and writes interests.
2. The app converts text to numbers using TF-IDF.
3. It finds the most similar careers using cosine similarity.
4. It shows the top 3 careers, the skills you have, skills to learn and a learning roadmap.

## Tech Used
Python, Pandas, scikit-learn, Streamlit

## Run Locally
```
pip install -r requirements.txt
streamlit run app.py
```
