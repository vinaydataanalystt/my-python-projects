# Restaurant Sales Analysis (Deployment)

A simple Streamlit dashboard that analyses restaurant sales data and is deployed online.

## Features
- Total sales, orders and items sold
- Monthly sales trend
- Sales by category, top 5 items, payment methods
- Filters for category and payment method

## Tech Used
Python, Pandas, Streamlit

## Run Locally
```
pip install -r requirements.txt
python generate_data.py
streamlit run app.py
```
